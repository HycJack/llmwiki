# Databases

A database is an organized collection of structured information stored and accessed electronically.

## Relational model

Relational databases store data in tables with rows and columns. SQL is the standard query language.

## Indexes

An index is a data structure that improves the speed of data retrieval operations on a table.

## Transactions

A transaction is a sequence of operations performed as a single logical unit of work, guaranteeing atomicity, consistency, isolation, and durability.
